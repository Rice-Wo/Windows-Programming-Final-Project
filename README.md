# Windows-Programming-Final-Project

本專案為課程學期專案，使用 C# WinForms 開發幾款小遊戲。	

## 專案內容

- 預計實作遊戲：
	1. 猜數字遊戲 (Guess the Number Game)
	2. 剪刀石頭布 (Rock-Paper-Scissors Game)
	3. 21 點 (Blackjack Game)

## 使用方式

進入後會有數個按鈕，分別對應不同遊戲，點擊按鈕後會進入該遊戲的介面。

### 剪刀石頭布

基本猜拳玩法。
進入後按下對應按鈕即可出對應拳。

### 猜數字

必須猜四位數字，數字可能重複。	
輸入到輸入框後按下Enter或是送出按鈕即可提交答案。

### 21點

基本21點玩法，按下要牌可以要牌，停牌則開始結算。
